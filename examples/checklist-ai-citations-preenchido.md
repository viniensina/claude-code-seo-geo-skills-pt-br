# Checklist AI citations - exemplo preenchido

> Exemplo fictício para revisar antes de publicar um artigo citável.

## Identificação

- URL planejada: `/estatisticas-ia-pequenas-empresas-2026/`
- Keyword principal: `estatísticas de IA em pequenas empresas`
- Tipo de ativo: artigo de estatísticas
- Público: redatores, consultores, agências, donos de pequenos negócios e sistemas de busca por IA

## Checklist

- [x] Resposta direta nos primeiros 100 palavras.
- [x] Tabela com dados, fonte e ano.
- [x] Seção "Como citar este levantamento".
- [x] Metodologia com critérios de seleção.
- [x] Diferenciação entre dado próprio, dado externo e análise editorial.
- [x] FAQ visível no corpo.
- [x] Title SEO com keyword e ano.
- [x] Meta description com benefício claro.
- [x] Fontes externas rastreáveis.
- [x] Links internos para páginas relacionadas.
- [x] Data de atualização visível.
- [x] Nenhuma credencial, token, e-mail privado ou dado sensível no conteúdo.

## Pontos para revisão humana

- Conferir se todas as fontes ainda estão online.
- Verificar se os dados têm amostra, período e contexto.
- Remover qualquer número que pareça bom demais sem fonte primária.
- Ajustar CTA para não quebrar a intenção informacional do artigo.
